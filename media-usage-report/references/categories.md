# 内容领域分类

使用 `scripts/classify.py` 的 `classify(title)` 按关键词将标题归类。对音乐、小说、播客等非视频内容，优先把 `title`、`creator`、`album`、`book`、`chapter`、`tags` 拼成一段可分类文本后再归类。规则按优先级顺序匹配，命中即返回。

## 使用建议

- 关键词按优先级排序，避免「车」这类泛词误伤（先匹配更具体词）。
- 抖音标题先剥离 `#话题` 标签再分类；小红书标题剥离语气词与 emoji。
- 音乐记录不要只看歌曲名；歌手、专辑、歌单名往往更能体现长期偏好。
- 小说记录不要只看章节名；书名、作者、题材标签和阅读进度更关键。
- 未命中归为「其他」，报告中注明该口径。
- 分类后可人工抽样校对（如每平台抽查 10 条），并把明显误判加入关键词。

## 画像总结写法

生成报告时用 3–5 句话总结偏好，模板：

1. 总体口味：`该账号内容口味比较杂食，但主线集中在 X、Y、Z`。
2. 第一大偏好：`其中 {AI/编程} 类最多（N 条），说明近期在 {学习 AI 工具链}`。
3. 次要偏好：`其次是 {美食}（N 条）和 {骑行/旅行}（N 条）`。
4. 稳定兴趣：`另外 {萌宠}、{游戏}、{汽车} 也稳定出现`。
5. 内容形态：`从形态看，{视频/图文/音乐/小说} 的占比更高，说明用户主要通过 {观看/阅读/收听} 获得内容`。
6. 画像概括：`整体呈现「...」的混合画像`。

示例见本次 B站报告：AI/编程 40 条、美食 27、骑行/旅行 22、萌宠 18、游戏 17、汽车 12，概括为
「AI 学习 + 下饭美食 + 户外骑行 + 萌宠游戏」。
